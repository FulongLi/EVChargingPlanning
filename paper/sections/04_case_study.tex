\section{Case Study and Experimental Setup}

The empirical case study focuses on the London Borough of Barnet. Barnet is an appropriate first test area for the proposed framework because it is a large outer London borough with heterogeneous residential density, town-centre activity, major road corridors, and an existing public charging network. This combination makes the area more informative than a small homogeneous test region while keeping the spatial scale manageable for transparent method development.

\subsection{Open Data Sources}
The current implementation uses OpenStreetMap data obtained through the Overpass API \cite{osmCharging,overpass}. The study-area bounding box approximates Barnet and is used as a reproducible spatial filter for the first version of the pipeline. The raw query extracts existing charging stations, parking locations, shops, offices, selected amenities, residential land-use polygons, major roads, and electrical substations. These features are converted to point-based proxy layers using node coordinates or way/relation centre points.

The processed Barnet dataset contains 576 demand grid points, 140 candidate sites, 92 existing charging-station records, 2197 parking features, 5144 point-of-interest features, 4115 major-road features, and 173 substation proxy features. The National Chargepoint Registry is not used as the default source because it has been decommissioned \cite{govukNCR}; therefore, OpenStreetMap is adopted as the reproducible open-data source for this study.

\subsection{Demand and Proxy Construction}
Because transaction-level charging demand is not available from the reproducible open-data inputs used in this study, demand is represented through an interpretable proxy model. The study area is discretised into a regular demand grid. For each grid point, residential demand is estimated from nearby residential land-use features, commercial and destination demand is estimated from nearby shops, offices, and amenities, and road-related demand is estimated from proximity to major roads and parking locations. The total charging demand score is computed as a weighted combination of residential, commercial, and road components.

Accessibility is represented by a composite proxy based on major-road proximity, parking density, and commercial activity. Grid risk is represented by a hosting-capacity proxy and a peak-load proxy. The hosting-capacity proxy increases near substations and decreases in locations with dense existing charging infrastructure, while the peak-load proxy increases in areas with stronger residential, commercial, and road-related demand. This does not represent a full distribution-network power-flow model. Instead, it provides a reproducible grid-awareness layer that can later be replaced by real hosting-capacity or network-constraint data.

\subsection{Candidate Site Generation}
Candidate charging sites are generated from parking locations, existing charging locations, and demand hot spots. To avoid selecting many nearly identical candidates in one activity centre, candidate sites are ranked by local demand intensity, accessibility, and grid risk, and then filtered using a minimum-distance diversity rule. This produces a spatially distributed candidate set while preserving a preference for practically plausible charging locations.

\subsection{Experimental Design}
Three clustering-based planning strategies are compared:
\begin{itemize}
  \item geographical K-means, which partitions demand points using only longitude and latitude;
  \item demand-weighted K-means, which uses demand as a sample weight in spatial clustering;
  \item grid-aware demand clustering, which uses spatial location, demand, accessibility, and grid-risk proxy features.
\end{itemize}

The calibrated London experiment uses \(K=9\) service zones and a grid-risk feature weight of 0.25. These values are selected from a sensitivity analysis over \(K \in \{5,\ldots,11\}\) and grid-risk weights from 0 to 1.5. The optimisation parameters are kept fixed across all methods so that differences in the results can be attributed to the service-zone partitioning strategy rather than post-hoc parameter tuning.

The main evaluation metrics are average demand-weighted service distance, demand coverage ratio, total investment cost, total grid-impact score, grid impact per installed charger, station utilisation mean and standard deviation, unserved demand, selected station count, and installed charger count.
